📘 Integration Quick Reference

1. Power Rule: $\int ax^n\,dx = \dfrac{ax^{n+1}}{n+1} + C \quad (n \neq -1)$
Add $1$ to the exponent, divide by the new exponent, and always include $+C$ for indefinite integrals.
2. Exponentials & Logs: $\int e^{kx}\,dx = \dfrac{1}{k}e^{kx} + C$  |  $\int \dfrac{1}{x}\,dx = \ln|x| + C$
More generally, $\int \dfrac{f'(x)}{f(x)}\,dx = \ln|f(x)| + C$.
3. Substitution: $\int f(g(x))g'(x)\,dx = \int f(u)\,du$
Set $u = g(x)$, compute $du = g'(x)\,dx$, and transform limits when definite.
4. Area Under Curve: $A = \int_a^b y\,dx$
Regions below the $x$-axis give negative integrals; take the absolute magnitude for physical area.
5. Volumes of Revolution ($360^\circ$)
About $x$-axis: $V_x = \pi \int_a^b y^2\,dx$  |  About $y$-axis: $V_y = \pi \int_c^d x^2\,dy$
